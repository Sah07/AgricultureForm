The Agriculture Form is a CoreUI-based frontend form used in an admin dashboard to collect and manage farmer and crop-related data. It is designed for a simple UI testing system (no backend required) and works using React state to store and display information instantly.

🎯 Purpose

This form helps simulate a real-world agriculture management system where an admin can:

Add farmer details
Record crop information
Store land and seasonal data
View data in a report table (frontend only)

🖥️ UI Purpose in Admin Dashboard

This form is used in:

✔ Agriculture management systems
✔ Farmer registration system
✔ Crop tracking systems
✔ Government agriculture reports
